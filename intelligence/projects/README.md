# Projects Intelligence

Projects Intelligence is the canonical company-memory stream for bounded business projects.

It turns yearly project, capacity, and implementation evidence into a conservative view of:

- what was announced
- what execution evidence later appeared
- whether the project progressed, stalled, completed, or remains unclear
- whether any business or financial effect is visible
- whether investor conviction should change

It does not try to be a project-management dashboard.
It interprets business execution.

The stream uses the shared Prometheus Progression Engine for chronology, deduplication, confidence, turning points, and validation.
